# Histograms

**Mr Nathan's Maths Tuition** · GCSE single-topic series

A step-by-step interactive course in histograms, from why unequal class widths matter to multi-step exam problems.

**Open it:** https://goyaklaarchimedes.github.io/Topic-Histograms/

## What's inside

- 16 sections: grouped data, class width, frequency density, drawing and reading histograms, missing values, unknown scales, estimating within classes, percentages and probabilities, modal class, estimating the median, and multi-step problems
- Worked examples, interactive tests and printable practice
- A full histogram mastery test

## Level

Intermediate and Higher. Suitable for AQA, Edexcel, OCR, WJEC and IGCSE.

## How to use it

Open the link in any web browser on a phone, tablet, laptop or interactive whiteboard. There is nothing to install, and no app, account or subscription is needed.

**Status:** Not yet on PayHip.
